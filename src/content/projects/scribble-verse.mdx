# Scribble Verse

Scribble Verse is a lightweight yet feature-rich digital whiteboard application that brings the simplicity and intuitiveness of pen and paper to your browser.

## Features

### Drawing Tools

- **Pen** with customizable color and size adjustment for natural drawing
- **Eraser** with adjustable size for precise corrections
- **Shapes** including line, rectangle, and circle for structured diagrams

### Workspace Control

- **Undo/Redo** functionality for non-destructive editing
- **Clear** option to quickly reset the canvas
- **Background color change** to customize your workspace

### Data Persistence

- **Dark and light mode** support
- **Save/Load** functionality using local storage for seamless session continuity

## Use Cases

Perfect for:

- **Quick ideation** and brainstorming sessions
- **Digital note-taking** during meetings or lectures
- **Diagram creation** for explanations and presentations
- **Collaborative planning** in distributed teams

## Technical Implementation

Built with vanilla JavaScript and HTML Canvas, keeping the application lightweight and fast. The Tailwind CSS integration provides a polished, modern interface while maintaining performance.

The local storage implementation ensures your whiteboard sessions persist across browser sessions, making it a reliable tool for ongoing projects.

## Design Philosophy

Scribble Verse prioritizes **simplicity** and **usability** - just like a physical whiteboard, you open it and start drawing immediately, without unnecessary complexity or distractions.
